# 결산 리포트

업로드한 로컬 CSV로 생산량, LOT SIZE, 가동률, 인당 생산량과 전력 지표를 조회하는 Streamlit 웹페이지입니다. MES 서버에 접속하지 않습니다.

## 설치 및 실행

Python 3.12 기준입니다.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## 데이터

실제 데이터는 저장소와 이 코드 묶음에 포함하지 않습니다. 현재 입력 경로는 프로젝트 아래 `v1/해커톤_업로드_2026`입니다. 데이터는 별도로 배치해야 합니다.

필요한 파일:

- `03_에이전트용/p_prod_result.csv`
- `03_에이전트용/p_prod_plan.csv`
- `01_분석용/p_grplot_list.csv`
- `01_분석용/HMI_feeder_list.csv`
- `01_분석용/p_prod_rpt.csv`
- `01_분석용/EMS_전력계_15min집계.csv`
- `01_분석용/전력요금_월별청구_2026.csv`

환경변수 `SLP_DATA`로 CSV 폴더를 지정할 수 있습니다. 지정하지 않으면 기본 `v1/해커톤_업로드_2026`을 사용합니다. `.env`는 자동으로 읽지 않으며 필수 비밀값도 없습니다. 정제 데이터의 파일·필수 컬럼 호환성은 사용 환경에서 확인해야 합니다.

팀 서버에서는 실행할 셸에서 다음과 같이 지정합니다.

```bash
export SLP_DATA='/data/hackathon/cleaned/해커톤_업로드_2026'
streamlit run app.py
```

`.env.example`은 설정 이름을 보여주는 예시입니다. 파일을 복사하는 것만으로 환경변수가 적용되지는 않습니다.

## 계산 기준

- 생산량: 선택 기간·호기·조의 생산실적 합계.
- 평균 LOT SIZE: 생산량 / 날짜별 라인·LOT 수의 합계.
- 통합 LOT SIZE: 생산량 / 날짜별 통합 묶음 수 합계. 연결표에 없는 LOT는 단독 처리.
- 가동률: RPM 250 초과 원본 행을 시간당 최대 60분으로 집계. 가동 이력 있는 호기·날짜만 분모에 포함하며, 해당 호기의 당일 정지·누락 시간은 분모에 유지.
- 인당 생산량: 생산일보 총원-결원 및 조 연결 보정 기준. 실제 근태 검증값이 아니며 호기별로 인원을 임의 배분하지 않음.
- 전력량: 한전 청구 자료가 있는 월은 청구 기준 추정 배분, 없는 월은 DB 센서 합계.
- 호기별 효율: 압출기·히터·부속 전력량 / 해당 호기 전체 조 생산량(톤). 공용 설비 제외. 청구 기준 전력은 달력일, 생산은 08:30 기준이므로 비교 시 고려 필요.

## 서버 설정과 예약

배포 서버 주소·접속 경로는 포함하지 않았습니다. 필요하면 Streamlit 실행 옵션 또는 서버 전용 설정으로 지정합니다.

팀 서버 이전 준비를 위해 예약 조회 조건 저장과 예약 등록·변경·해제 UI를 임시 제거했습니다. 화면에서 수동으로 리포트를 조회·다운로드·저장할 수 있습니다. CLI와 `configure_schedule()` 함수는 복원용으로 유지합니다. 예약 함수를 다시 연결하기 전 `/data/hackathon` 고정 경로, UTC 시간대, Linux cron 권한을 확인해야 합니다.

## 파일 구성

- 실행 코드: `app.py`, `pages/` 및 루트의 계산·집계 모듈

웹 실행에는 `tests/`가 필요하지 않습니다. 테스트는 프로젝트 루트에서 아래 명령으로 실행합니다.

## 테스트

가상 인원 fixture를 명시적으로 전달하므로 운영 CSV 없이 실행할 수 있습니다.

```bash
python -m unittest discover -s tests -t . -p 'test_*.py'
```

원본 데이터·인사정보·보고서·캐시·환경설정 비밀값은 `.gitignore`로 제외합니다. 공개된 실제 데이터가 포함된 시연용 앱이 아닙니다.
