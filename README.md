# 결산 리포트

업로드한 로컬 CSV로 생산량, LOT SIZE, 가동률, 인당 생산량과 전력 지표를 조회하는 Streamlit 웹페이지입니다. MES 서버에 접속하지 않습니다.

## 설치 및 실행

Python 3.12 기준입니다.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## 데이터

실제 데이터는 저장소와 이 코드 묶음에 포함하지 않습니다. 현재 입력 경로는 프로젝트 아래 `v1/해커톤_업로드_2026`입니다. 데이터는 별도로 배치해야 합니다.

필요한 파일:

- `03_에이전트용/p_prod_result.csv`
- `03_에이전트용/p_prod_plan.csv`
- `01_분석용/p_grplot_list.csv`
- `01_분석용/HMI_feeder_list.csv`
- `01_분석용/p_prod_rpt.csv`
- `01_분석용/EMS_전력계_15min집계.csv`
- `01_분석용/전력요금_월별청구_2026.csv`

현재 코드는 `.env`를 읽지 않으며 필수 비밀값도 없습니다. 입력 경로를 바꾸려면 `production_report.py`의 `DATA`를 변경해야 합니다. 정제 데이터로의 전환은 포함하지 않았습니다.

## 계산 기준

- 생산량: 선택 기간·호기·조의 생산실적 합계.
- 평균 LOT SIZE: 생산량 / 날짜별 라인·LOT 수의 합계.
- 통합 LOT SIZE: 생산량 / 날짜별 통합 묶음 수 합계. 연결표에 없는 LOT는 단독 처리.
- 가동률: RPM 250 초과 원본 행을 시간당 최대 60분으로 집계. 가동 이력 있는 호기·날짜만 분모에 포함하며, 해당 호기의 당일 정지·누락 시간은 분모에 유지.
- 인당 생산량: 생산일보 총원-결원 및 조 연결 보정 기준. 실제 근태 검증값이 아니며 호기별로 인원을 임의 배분하지 않음.
- 전력량: 한전 청구 자료가 있는 월은 청구 기준 추정 배분, 없는 월은 DB 센서 합계.
- 호기별 효율: 압출기·히터·부속 전력량 / 해당 호기 전체 조 생산량(톤). 공용 설비 제외. 청구 기준 전력은 달력일, 생산은 08:30 기준이므로 비교 시 고려 필요.

## 서버 설정과 예약

배포 서버 주소·접속 경로는 포함하지 않았습니다. 필요하면 Streamlit 실행 옵션 또는 서버 전용 설정으로 지정합니다.

자동 리포트 등록 기능은 Linux crontab과 UTC 서버를 전제로 합니다. 현재 예약 명령은 `/data/hackathon` 경로를 사용하므로 다른 위치에 설치하면 `configure_schedule()`과 화면 안내의 실행 경로를 수정해야 합니다. 예약 등록은 화면에서 별도로 실행합니다.
